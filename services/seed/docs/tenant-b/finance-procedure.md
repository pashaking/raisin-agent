# Charity B finance procedure after a declined donation (tenant-internal)

Charity B treats every declined donation as a customer-service touchpoint. The finance assistant reviews declines each Monday, groups them by decline category, and sends one summary to the development director. Donors with an insufficient funds decline receive a friendly retry message ten days later. Donors with an expired card receive the update-your-card link immediately. Charity B never phones donors about declines. Reconciliation happens in the quarterly close, not monthly.
